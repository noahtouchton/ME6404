# ME6404

## Final project: optimal swing-around maneuver for the tower crane

The payload has to get around a pin that the trolley can't reach, so it has to
swing around it, then return to rest at its starting state with zero residual
vibration. The trajectory comes from Pontryagin's minimum principle: a
two-point boundary value problem solved with `bvp4c`, within the fixed hardware
limits on trolley, hoist and slew velocity and acceleration.

### Layout

```
final_project/
├── find_path.m        1. solve the loop around the pin (fixed t_f) -> results/crane_solution.mat
├── find_min_time.m    2. (optional) shrink t_f to the fastest admissible loop, updates the same file
├── run_sim.m          3. load the saved solution: plots, checks, 5 s coast, 3D animation (no solving)
├── model/
│   ├── EOM.m          symbolic dynamics, costates, optimal control -> writes model/generated/
│   └── generated/     auto-generated by EOM.m (don't edit by hand)
├── lib/               shared helpers: BCs, solver wrappers, geometry, admissibility metrics
├── results/           saved solutions (.mat)
└── archive/           old single-file version (out of date, kept for reference)
```

### Usage

Open `final_project/` in MATLAB, then:

1. `run_sim` to demo the saved solution right away.
2. `find_path`, then `find_min_time`, to re-solve from scratch.
3. After changing the model or cost, run `model/EOM.m` first to regenerate
   `model/generated/`. If you add or reorder parameters, update `lib/crane_params.m` to match.
